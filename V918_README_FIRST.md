# V9.18 — U.S. transportation and agricultural methane mitigation

Current reproducible release for the Research Article by J. K. Bily, C. Pahl and P. Valdés Bacallao. This is a conditional national annual techno-economic screening study, not a validated forecast or complete lifecycle assessment.

## Reproduce in a flat checkout

Use Python 3.13 (tested on Linux); install pinned dependencies once: `python -m pip install -r requirements-v918.txt`. Run `sh RUN_V918.sh` (Linux/macOS) or `RUN_V918.bat` (Windows). `INSTALL_V918.bat` is the Windows install wrapper. Run from a clean extracted code/data ZIP or a Git checkout containing all release files in the repository root; do not unpack the embedded data ZIPs. No API key, internet, private Word documents or absolute paths are needed during numerical reproduction. The V9.18 runner first reproduces the earlier V9.17 historical diagnostics, then calculates 30 current comparisons, generates the updated numerical Figure S33, and checks the active reference, crop exclusions, NPK and methane conservation, combined cost and avoided emissions, and 72 original artwork hashes. Windows launcher provided but not independently tested on native Windows.

Primary results: `US918_Evidence_Results.json`, `us918_evidence_scenarios.csv`, `us918_waste_streams.csv`, `us918_state_crop_allocation.csv`, `us918_state_historical_resources.csv`, `us918_bt23_national_curves.csv`. `ScienceFigS53_V918_Evidence_Constrained.tif` is the current Figure S33 (600 dpi). All earlier figures are historical comparators. V9.17 figures and numerical results remain reproducible as historical files; older V9.14–V9.16 LHV/rounded reference values are NOT the active reference.

## Corrections and interpretation

* The active AEO2026 reference comes directly from `US97_AEO_Boundary.json` (stock-weighted 15-year straight-line case; provisional AEO H₂ HHV convention): 1,629.014882 Mt CO₂e/year, $477.148742 billion/year. The older approximate LHV reference (1,638.8 Mt) remains only a historical sensitivity. Physical biomethane energy remains LHV.
* Central integrated cost $667.119412 billion/year; $9.152643 billion/year savings versus continued petroleum at inherited late-2025 prices; $189.970669 billion/year more expensive than the partially electrified AEO2026 reference. Higher inherited petroleum-price sensitivity savings $340.58 billion/year, not a 2050 price forecast.
* Central transport-only mitigation before biomethane substitution is 91.89% versus continued petroleum and 83.61% versus AEO2026; combined incremental mitigation (including separate agricultural methane) is 3.064 and 1.401 Gt CO₂e/year, respectively. Not a percentage of all U.S. emissions.
* Central crop selection 102.64 Mt/year includes 95 Mt of individually unverified categories, 6.94 Mt constrained by wet-waste inventory and 0.70 Mt mapped by group (corn cobs/husks proxy). The national cap is not feedstock-specific empirical validation. The three new central-assumption restrictions independently reoptimize transport and wet-waste routing: BT23 mapped groups only (26 Mt; $0.065bn crop-specific saving); mapped + wet-bounded streams (32.94 Mt; $0.372bn); narrower restriction without cobs/husks or mixed small-grain proxies (0 Mt; $0 crop-specific saving). Broader integrated late-2025 price savings persist at $4.48bn, $4.79bn and $4.41bn; respective combined mitigation 3.046, 3.048 and 3.040 Gt/year. No candidate pathway was deleted from the central model.
* Prior Monte Carlo outputs are explicitly historical V9.14 and V9.15 diagnostics, not V9.18 joint uncertainty. The new comparisons are deterministic, not probability estimates. Original programme options, Grid Harvester and artwork retained. The available public evidence does not establish 2050 sustainable supply, field-level costs or adoption, and exact county BT23 offered-price curves remain unavailable.
* See `V917_README_FIRST.md` for detailed source provenance, historical resource definitions, wet-waste overlap rules and prior assumptions. Legacy runners and outputs are retained; use V9.18 for current results. Two preserved TIFF sources have insufficient native resolution for a true 600 dpi print at intended size; do not claim that metadata upscaling resolves this.

## Public release and validation

Upload all extracted files to the repository root, not the outer ZIP. Existing historical files can remain. All supplied individual files are below GitHub's 100 MB limit. `MANIFEST_V918_SHA256.csv` lists supplied file SHA-256 values (excludes itself). `V918_GIT_BLOBS.csv` is a manifest of expected Git blob hashes; run `python VERIFY_GITHUB_V918.py main` (or pass a release commit/tag) after upload to verify expected root files on GitHub. The Git blob manifest excludes itself and the outer SHA manifest to avoid circularity. A matched remote tree does not by itself execute the code: rerun `RUN_V918` from a fresh checkout. Record the pinned commit URL for the editor. A public release must be checked after upload; no final version-matched commit is asserted here. Final coauthor approval, author contributions, artwork provenance and journal compliance remain author responsibilities.
